## 3. RAG Engine Usage

```bash
# Query the RAG engine for grounded classical verdicts
python3 scripts/rag_engine.py --ask "How is Neechabhanga Raja Yoga formed according to classical texts?"
python3 scripts/rag_engine.py --ask "What are the effects of Jupiter in the 10th house on profession?"

# Search specific texts
python3 scripts/rag_engine.py --book PHALADEEPIKA --query "Neecha Kendra exaltation"
```
